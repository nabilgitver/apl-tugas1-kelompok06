# Bukti sumber data

Isi folder ini: ringkasan wawancara dan tangkapan layar yang dipakai sebagai sumber data.

Aturan:
1. **Tanpa identitas pribadi.** Tutup nama, stambuk, nomor telepon, dan email pada tangkapan layar. Untuk topik MSIB, tutup juga isi logbook, nilai, serta nama dosen pembimbing dan mitra.
2. Responden ditulis berdasarkan peran saja (contoh: "mahasiswa peserta magang", "dosen pembimbing", "staf unit akademik"), tidak dengan nama.
3. Tidak ada data yang diambil dengan menguji keamanan sistem.
4. Satu berkas per wawancara, dengan nama `wawancara-01.md`, `wawancara-02.md`, dan seterusnya (salin dari `wawancara-templat.md`).
